# タケエイ仕分け: 種類別・難易度別のデータ収集ルール

起案 2026-10-20（Kota の方針転換）。2026-10-19 の「山から何でも 1 個拾って左右へ」汎化収集
（`kitakyushu-takeei-v1`）を置き換える。

## 全体の構成（なぜこう録るか）

実際の仕分けは 2 層に分ける。

1. **上位プログラム**: 画像から物体の種類を認識し、掴む順番を決める。
2. **種類別の VLA**: 「木材を掴んで木材の箱へ置く」のように、掴む物に応じた VLA を呼び出す。

このため、データも **種類ごとに別の VLA を学習できる単位** で録る。
1 つの VLA は 1 種類だけを扱い、言語指示もその種類専用の 1 文に固定する。

## 収集の単位

**種類 × レベル（1〜4）ごとに 50 エピソード**。

| 種類 | slug | 状態 |
|---|---|---|
| 木材 | `wood` | **最初に着手**（L1 から） |
| 紙（ダンボール） | `cardboard` | 未着手 |
| 発泡スチロール | `styrofoam` | 未着手 |
| （その他・追加時にここへ足す） | | |

### レベルの定義（全種類で共通）

| レベル | 画角内の状態 | 対象物の見え方 |
|---|---|---|
| **L1** | 対象の種類の物体 **1 個だけ** | 全体が見えている |
| **L2** | 他の種類の物体も画角にある | **隠れていない**（離れて置かれている） |
| **L3** | 他の種類の物体と重なっている | **少し隠れている** |
| **L4** | 他の種類の物体の下にある | **完全に隠れた状態から始める** |

- どのレベルでも、1 エピソードで行うのは「対象を 1 個拾って、その種類の置き場へ置く」まで。
- **全エピソードで両腕を使う**（片腕だけのエピソードは録らない・2026-10-20 Kota 決定）。
  片腕を固定する `FREEZE_SIDE` は env に書かない。
- L4 は、覆っている物をどけてから対象を拾う動作まで含む（どけた物の置き方はレベル 4 の着手時に決める）。

### 置き場所

- 種類ごとに **固定の置き場（箱）** を決める。
- **木材の箱: ロボットの真正面、木材より奥側**（実寸と位置はシーンファイルに実測で書く）。

## 名前の付け方

| 項目 | 規則 | 木材 L1 の例 |
|---|---|---|
| TASK_SLUG | `takeei_<種類>_l<レベル>` | `takeei_wood_l1` |
| シーン | `scenes/<拠点>-<種類>-l<レベル>-v<版>.yaml` | `scenes/kitakyushu-wood-l1-v1.yaml` |
| env | `config/bimanual-collect.takeei_<種類>_l<レベル>.env` | `config/bimanual-collect.takeei_wood_l1.env` |
| データセット | `Orboh/bi_openarm_<TASK_SLUG>_<obs>_v1_<日時>` | `Orboh/bi_openarm_takeei_wood_l1_chest_wristr_wristl_v1_…` |

- **言語指示（TASK）は種類ごとに 1 文で固定し、レベルでは変えない**。
  レベルは「データの条件」であって「指示」ではないため。推論時に上位プログラムが渡す文と完全に一致させる。
  - 木材: `Pick up the wood and place it in the box`
- レベルはシーンファイル（`level:`）と TASK_SLUG に残し、学習時にレベル単位で選んだり混ぜたりできるようにする。

## 本数の配分（1 種類 × 1 レベルあたり 50 本）

`collect_bimanual.sh` の流れに合わせる。

1. `dry`（2 本・捨て名）: 配管とキー操作の確認
2. `gate`（10 本）: 止めて検査する（`length` と動画区間の整合、画角、置き場が写っているか）
3. `session s2 40`（40 本）: 合計 50 本

## 学習の進め方（案）

- まず **木材 L1 の 50 本だけ** で学習し、L1 環境で成功率を測る（パイプラインの確認を兼ねる）。
- L2 以降は、録るたびに「L1〜Ln を混ぜて学習」と「Ln だけで学習」を比べ、混ぜた方が良いかを判断する。
